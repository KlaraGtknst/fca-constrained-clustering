\begin{frame}{The Second Lattice Is Data-Driven}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.48\textwidth}
\begin{itemize}
    \item Documents are represented by \ac{lda} topic memberships.
    \item Topic incidences are thresholded into a formal context.
    \item An iceberg concept lattice keeps frequent document-topic concepts.
    \item This follows prior topic-model-based \ac{fca} hierarchy generation~\cite{blei2003lda,gutekunst2025conceptual}.
\end{itemize}

\begin{frame}{Consistency Lattice: Exact Agreement}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.48\textwidth}
\begin{itemize}
    \item A concept is consistent if its extent is closed in both closure systems.
    \item This is the strict intersection of the expert \ac{mlb} lattice and the topic-model lattice.
    \item It asks for identical document clusters.
\end{itemize}

\vspace{0.5em}
\begin{alertblock}{BankSearch result}
Only trivial shared concepts remain. Exact agreement is too strict for this practical setting.
\end{alertblock}
\end{column}

\begin{frame}{From Exact Agreement to Degree of Agreement}
\begin{itemize}
    \item The practical question is not only whether two concepts are identical.
    \item We need to know whether an expert concept and a data-driven concept cover mostly the same documents.
    \item We compare concept extents with Jaccard similarity~\cite{Glckstad2013UnsupervisedKS}:
\end{itemize}

\[
J(A,B)=\frac{|A\cap B|}{|A\cup B|}
\]

\begin{block}{Interpretation}
$J(A,B)=1$ recovers consistency; lower thresholds reveal partial agreement between heterogeneous knowledge sources.
\end{block}
\end{frame}

\begin{frame}{BankSearch Agreement Matrix}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.43\textwidth}
\begin{itemize}
    \item Most expert/data-driven concept pairs have near-zero overlap.
    \item The non-trivial agreements are concentrated in a few recognizable domains.
    \item This motivates a coherence lattice instead of stopping at consistency.
\end{itemize}

\begin{frame}{Coherence Lattice: Practical Agreement}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.48\textwidth}
\begin{itemize}
    \item Keep concept pairs whose extent overlap exceeds a threshold $\theta$.
    \item For BankSearch we use $\theta = 0.5$ to show meaningful partial agreement.
    \item The resulting lattice exposes where manual categories and topic evidence support each other.
\end{itemize}
\end{column}

\begin{block}{Story resolution}
The case study shows why the \ac{fca} hierarchy is useful: it provides intensional descriptions, while consistency and coherence explain how far those descriptions agree with expert structure.
